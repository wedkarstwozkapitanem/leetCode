## ▶️ Uruchamianie
C++ (Linux)
```shell
g++ solution.cpp -O3 -std=c++23 -o solution
./solution < input.txt
```

C++ (Windows PowerShell)
```shell
g++ solution.cpp -O3 -std=c++23 -o solution
Get-Content input.txt | ./solution
```
Python
```shell
python solution.py < input.txt
```
